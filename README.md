## 🌌 About the Experience

This isn't a traditional portfolio. It's a **3D universe you navigate through**.

Each section of the portfolio is a destination in deep space — a Milky Way galaxy at the entrance, an orbiting solar system behind the About section, floating skill orbs in the skills nebula, and four interactive planets that each represent a real AI project. Tapping a planet triggers a cinematic burst animation and reveals that project's story.

Built entirely with **vanilla JavaScript, Three.js, and native ES modules** — no build tools, no frameworks, no bundler.

## 🛠️ Technology Stack

### 3D & Rendering
- **Three.js** v0.160 — scene graph, geometries, materials, particle systems, WebGL renderer
- **WebGL** — hardware-accelerated 3D via the browser
- **Canvas 2D API** — procedural planet texture generation and burst animations

### Frontend
- **Vanilla JavaScript** — ES2022 modules, classes, async patterns
- **HTML5** — semantic markup, `importmap` for zero-bundler module resolution
- **CSS3** — custom properties, glassmorphism, `clamp()` fluid typography, `env()` safe areas

### Architecture
- **Native ES Modules** via `importmap` — no bundler, no `node_modules`, no build step
- **CDN dependencies** — Three.js and GSAP loaded directly from jsDelivr
- **Adaptive quality system** — auto-scales rendering fidelity based on `hardwareConcurrency` and user agent

## 🏗️ Architecture

```text
portfolio/
├── index.html          # Entry point — HTML structure, importmap, all section overlays
├── js/
│   ├── main.js         # Three.js scene, solar system, camera system, navigation, animation loop
│   ├── universe.js     # Interactive planet system — per-planet WebGL scenes, burst animator, modal
│   └── data.js         # Skills and projects — single source of truth
├── styles/
│   ├── index.css       # Design tokens, reset, safe-area insets, responsive globals
│   ├── overlay.css     # Section overlays, glassmorphism cards, hero, about, skills, contact
│   ├── ui.css          # Navbar, mobile drawer, section indicators, project modal
│   └── universe.css    # Planet stage, mobile projects page, planet labels, burst canvas
├── sitemap.xml
└── README.md
```

**Key design decisions:**

- **Zero build step.** Runs directly as static files via `importmap`. Any static server works.
- **Layered z-index system.** Three.js canvas (z: 0) → HTML overlays (z: 10) → nav chrome (z: 100+) → modals (z: 300).
- **Dual planet architecture.** Desktop uses a 2×2 CSS grid inside the fixed overlay system. Mobile uses a separate scrollable DOM layer (`#mobile-projects-page`) with its own set of WebGL canvases — solving the viewport-height clipping problem that a single fixed overlay creates.
- **Per-planet WebGL scenes.** Each project planet is an independent `THREE.WebGLRenderer` instance on its own `<canvas>`, keeping planet interactions isolated and performant.

## 🚀 Running Locally

No Node.js required for the portfolio itself. You just need a static file server (browser ES module CORS policy blocks `file://`).

```bash
# Clone
git clone https://github.com/YashMhasekar/portfolio.git
cd portfolio

# Serve — pick any option:
npx -y serve .               # Node.js (no install)
python -m http.server 3000   # Python 3
```

Open **http://localhost:3000**
